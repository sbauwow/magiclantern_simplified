## ZOOM (crop) BASE — the native center-crop readout (from 02_zoom_x5.txt, 73 regs)

CMOS deltas on zoom entry (normal -> zoom):
  c6: 800 -> A6A     (THE crop-mode bit — biggest single discriminator)
  c7: 001 -> 401
  c4: 014 -> 2D4
  c5: C64 -> C60
  (c1/c2/c3 unchanged: whatever the underlying movie mode was)

ADTG deltas on zoom entry:
  8000: 0 -> 0005 (x5)  / 0006 (x10)   <- zoom-level selector
  805F: -> 00C5 (x5)    / 00E9 (x10)   <- blanking pair (always written together)
  8061: -> 00C5 (x5)    / 00E9 (x10)
  8172: -> 067D (x5)    / 06F0 (x10)   <- readout window start/size pair
  8173: -> 0684 (x5)    / 05FE (x10)
  8882-8888 quartet: -> 0410 0410 0413 0412 (both zoom levels)

x5 and x10 differ ONLY in: 8000, 805F/8061, 8172/8173.
=> PRESET RECIPE: base = zoom table; to size a window, scale/vary
   805F/8061 (blanking) + 8172/8173 (window) + 888x quartet (per-mode
   value seen: 0410-family zoom, 040B/0415/0417/041C families normal).
   Calibrate pixels-per-unit from ONE zoom-mode raw buffer dump next hw run
   (raw_info active_rect in x5 vs x10 gives the mapping for 8172/8173).
